# 接口完整性分数与 IQ 题库扩展计划

> 本计划只针对当前本地工作树。接口完整性分数与 IQ 分数分开保存、分开展示；旧报告不重算、不修改。检测任务以 Job 为单位，Job ID 从提交即为分享 ID，24 小时到期清理。

## 目标

1. 增加独立的“接口完整性分数”，衡量接口协议和证据链是否完整，不把缓存、联网或工具能力当作模型智力。
2. 扩展 IQ 题库，吸收 iqbench 中已有求解器和稳定判分题型，同时保留现有五题结果的兼容性。
3. 所有新题必须有确定答案、参数化或独立验证器；网络失败不能被判为模型能力失败。

## 评分边界

### 接口完整性分数

满分 100，按适用且成功返回的证据归一化。未支持、字段缺失和未验证不直接记 0，而是降低覆盖率并显示原因。

| 项目 | 权重 | 通过条件 |
|---|---:|---|
| 注入大小 | 20 | 合并三发中的前两轮采样成功、截距有效 |
| 缓存读写链 | 20 | 同一递增对话的三发串行读/写衔接通过，并计算 `第三轮读取 ÷ (第二轮读取 + 第二轮写入)`；字段缺失时降低覆盖率，不按0通过 |
| 工具调用 | 20 | tool name、call id、随机参数、结果回传全部通过 |
| 联网证据 | 15 | 服务端搜索块完成并有来源 URL；Chat 无统一协议则 unknown |
| 流式完整性 | 15 | 正确 SSE、结束事件、无中断；从注入/工具请求汇总 |
| Claude 思维链 | 10 | 仅 Claude 适用；摘要文本非空且签名存在 |

`score = round(availableEarned / availableWeight * 100)`，同时返回 `coverage = availableWeight / applicableWeight`。没有任何可计分证据时 score 为 null。该分数不进入 IQ，不代表模型智力。

### IQ 扩展

现有 Q1/Q4/Q6/Q8/Q7 保持原内部 ID 和答案，新增：

| 内部 ID | 题型 | 分值 | 判分 |
|---|---|---:|---|
| Q2 | 洗车路径 | 5 | 开车/驾车/自驾；步行、打车、骑车为 0 |
| Q3 | 球拍与球 | 6 | 0.05 全分，数值等价 |
| Q5 | 船锚水位 | 10 | 下降+排水/浮力/体积/密度理由全分；只答下降半分 |

新一轮题目顺序为 Q1～Q8，界面序号按数组顺序展示。旧报告的 `scoring_version` 保持旧值，不能用新卷面回写历史。

## 实施批次

### Batch 1：契约和纯函数

- 新建 `internal/integrity/score.go`：组件、覆盖率、归一化算法。
- 为每个边界写表驱动测试：全通过、部分未知、无可用证据、Claude/非 Claude 适用差异。
- 新增 Q2/Q3/Q5 生成器、判分器和回归测试。

### Batch 2：后端编排

- 在 `Verdict` 增加 `integrity`，保持 IQ 字段不变。
- 任务结束后从已有 probe 结果生成接口完整性分数，不重复发送请求。
- 历史 JSON 保存新字段；旧记录读取时显示“未生成”。
- 注入大小与缓存读写共用三次递增对话请求；三点拟合先扣除前轮输出与每轮协议包装，作为可解释的近似值，不再单独发送重复缓存请求。
- 默认单次上游请求超时360秒；每个调用独立最多重试3次，任务报告保存总耗时与最近一次运行耗时。

### Batch 3：前端报告

- 结果 API 类型增加完整性分数和 Q2/Q3/Q5。
- 新增“接口完整性”卡：总分、覆盖率、每项状态、未验证原因。
- IQ 卡继续显示 Q1～Q8，旧报告按已有题目数组显示。
- tooltip 解释“完整性不是智力”，不增加大段说明。

### Batch 4：验证

- `go test -race ./...`、`go vet ./...`。
- 前端 `npm test`、`npm run typecheck`、`npm run build`。
- mock 验证接口完整性归一化、历史兼容和新题判分。
- 浏览器验证结果卡、窄屏和 reduced-motion。
- 前端轮询只在任务状态变化或必要历史刷新时取数；完成任务停止轮询，隐藏/离线暂停，关闭历史链接自动预取，避免重复数据包。

## 不加入 IQ 的候选

- 知识截止日期、联网、缓存、工具调用、SSE、协议错误和注入大小：都是接口/时效/基础设施证据。
- LLMprobe 的身份自报、渠道签名和联网嫌疑：用于标签和审计，不足以形成智力分数。
- iqbench 的几何 SVG、17 题完整卷面：需要渲染器和更长任务时间，本轮不强塞进简单便携检测。
