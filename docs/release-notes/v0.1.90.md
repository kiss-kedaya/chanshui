# v0.1.90

- 新增全站俄语（`Русский` / `ru` / `ru-RU`）支持：
  - 语言切换菜单、首屏无闪烁防抖脚本、`detectLang`、`intlLocale` 与 4 份词库（全量 6 语列）完整接入俄语，并同步适配俄语印章与标签字号。
- 推理表现支持逐题实时显示：
  - 后端每完成一道推理题（并发模式与多轮对话模式同步）即增量拼装 `verdict.iq`（含 `done_count` / `total_questions` 与实时分数）并即时持久化；
  - 前端「推理表现」在首题完成后立刻渲染已答题目与实时进度徽章（`已完成 x / 9 题`），未完成题目紧随下方展示「检测中 / 等待中」，不再等待全卷结束才隐藏骨架屏。
- 修复非中文界面残留后端中文报错：
  - 新增 `web/lib/error-i18n.ts` 统一翻译后端报错与明细模板（含 `Claude 缓存首写未建立：前缀已到 N 字符`、`整单失败`、`FriendlyError` HTTP 状态/重试次数、指纹/注入/缓存采样报错、协议校验与深度体检明细），接入 `ErrorFold`、`ResultCards` 与 `ScoreHero`，英文/俄语/日韩/繁体界面不再漏出简体中文。
