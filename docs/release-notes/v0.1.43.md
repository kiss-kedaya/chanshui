# v0.1.43

指纹自适应采样，移除隐藏指令检测。包含 v0.1.42 的只读缓存修复。

## 指纹自适应采样

- 从 3 个有效样本开始；顶部候选概率达到 90% 就停止。
- 未达到 90% 继续采样，每次最多补 3 个，直到 10 个样本或请求预算用完。
- 卡片显示 `有效样本 N / 10`；提前停止时提示已达到 90%，取满 10 个仍未达到时提示未达到 90%。
- 数字候选概率仍只在数字库内比较；行为归因逻辑不变。

## 隐藏指令检测移除

- 新检测不再启动隐藏指令探针，不再生成隐藏指令卡片。
- 公共 API 的板块列表、OpenAPI 枚举和文档同步移除 `hidden`。
- 总分按剩余适用项重新分配；全通过仍是 100。
- 旧报告是保存时的快照，不自动重算；历史里已有的隐藏指令数据不再展示新卡片。

## 缓存只读修复（沿用 v0.1.42）

- 只读缓存模型允许首轮读取字段缺失；从首个已上报读取起验证，至少 2 个已上报读取且末轮读取大于 0 即通过。
- 末轮缓存率 = 末轮读取 ÷ 末轮总输入；缺失写入不按 0。

## 验证

- Go 全量测试、`go vet`、相关包 `go test -race` 通过。
- 前端 25 项测试、`typecheck`、`build` 通过。
- 指纹采样上限字段和 90% 目标写入结果，旧报告继续按 3 样本展示。

## 升级

- 无数据库迁移，按滚动流程排空后切换。
