# v0.1.33

加入DeepSeek Flash数字指纹基线，支持`deepseek-flash`及用户确认的`deepseek-v4.1-flash`别名。

- 官方接口采集36个有效训练样本、12个独立验证样本；4组三题验证均命中。原始证据与重建工具一并保留，不保存密钥。
- 数字检测和模型选择识别新候选，别名共用一份基线；官方API自动转换为其接受的`deepseek-flash`名称。
- 本地参考在启动、缓存恢复、远程库更新时合并，避免后台同步覆盖。
- 新基线使用16384输出预算，给默认推理和最终数字答案留出空间。报告注明单接口采样来源和概率未重校准的限制。

验证：Go竞态测试、原库oracle、新模型独立保留集、同步/重启保留、别名请求与前后端评分一致性。
