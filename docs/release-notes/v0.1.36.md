# v0.1.36

加入 `gpt-6.1-sol` 和 `claude-fable-5` 数字指纹，数字候选总数增至22。

- `gpt-6.1-sol`：72个有效训练样本、12个独立保留样本，穷举全部220组三题的归因命中率为98.2%。
- `claude-fable-5`：36个有效训练样本、12个独立保留样本，穷举命中率为100%。
- 两个模型均以供应商前缀名称登记别名（`openai/gpt-6.1-sol`、`anthropic/claude-fable-5`），实际请求名与归因候选共用同一基线，不会因为前缀被判成型号不符。
- 修复指纹项计分：候选之间概率接近（低置信）时不再判为掺水。此前 `used_outputs>=3` 就给分、不看置信度，`gpt-6.1-sol` 与 `gpt-6-astra` 这类近似平局会被误标。
- 建库验证改为穷举全部保留三题，不再只测4组固定分块；此前固定分块掩盖了约15%的误判率。
- 采集工具新增 `-rotate-invalid`：失败题目重试时改出新题。上游安全策略拒答的题目重发同一道永远拿不到样本。
- 保留原始采集、失败证据和重建步骤，不保存API密钥。候选权重仍有单接口及未重校准的限制。

## 验证方式

- `gpt-6.1-sol`：抽到近似平局时指纹项不再显示掺水；真实掺水（如 `claude-opus-4-6` 判成 `claude-sonnet-4-5`）仍照常扣分。
- 提交 `openai/gpt-6.1-sol` 检测，指纹项应归因 `gpt-6.1-sol`，不再误判为 `gpt-6-astra`。

## 已知限制

`gpt-6-astra` 不在本库中，仅作为上游 ModelTrace 库自带候选参与竞争。其长指纹请求在当前上游持续返回 502，未采到对称样本。
