# v0.1.47

管理员页新增指纹采集与归因快捷入口。

## 指纹采集

- 管理员可在 `/admin` 填入网关、Key、请求模型名、归因 ID 和显示名，直接开始采集。
- 一键填入浏览器上次保存的网关和 Key；Key 只用于本次采集，不落库。
- 可拉取上游模型列表，直接选请求模型名。
- 默认 36 个训练样本 + 12 个保留样本，也支持 30～40 / 9～12（3 的倍数）。
- 采集进度显示已完成、训练可用、保留可用；支持取消。
- 保留样本按 3 个一组归因，全部命中新 ID 才写入自定义指纹库；失败不写入。
- 自定义指纹持久化到 SQLite，重启后保留；支持删除，删除后已有报告不重算。
- 官方模型及其别名不可被自定义指纹覆盖；冲突直接拒绝。
- 自动同步 ModelTrace 时保留自定义指纹，不会在后台同步后丢失。
