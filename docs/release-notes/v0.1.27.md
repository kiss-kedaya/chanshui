# v0.1.27

新增隐藏指令检测、访客绑定与本地密钥保管，并把首页收回到「只做新建检测」。

## 隐藏指令检测（新板块）

上游可以在 `usage` 里少报甚至抹平被注入的 token，靠读上报的 token 数测不出隐藏提示词。
新板块 `hidden` 改从两个上游难以同时伪装的证据判定「有没有被注入」：

- **自述一致性**：同一件事用 6 种问法各问一遍。承认存在前置指令与否认系统提示词
  同时出现，即判注入。
- **自报身份**：把模型自报的知识截止日期与该模型家族的真实截止日期比对，明显偏早
  即判假身份。

不依赖上游上报的 token 数，因此不受计数抹平影响。报告新增「隐藏指令检测」卡片，
可展开查看每种问法的原始回答与判读。总分权重相应调整（总 100 不变）。

## 首页只做新建检测

- 提交检测后直接跳 `/history?id=<report_id>`，结果、重跑、导出都在报告页。
- 首页不再渲染时间线、结果卡片与重跑按钮，也不再用 `?job=` 恢复上一次任务。
- 失败项重试移到报告页原位执行。

## 访客绑定

首次访问生成匿名浏览器标识并落盘，随请求以 `X-Visitor-ID` 发送；服务端只保存其
SHA-256，据此判断报告归属。同一浏览器回访可认领自己的任务，即使当时的临时 jobkey
已不在。鉴权接受两种能力：`X-Job-Token`（创建时下发）或 `X-Visitor-ID`（本浏览器）。

用户填写的上游 API Key 仍然不落盘、不存储、不进数据库。

## 本地密钥保管

报告页重试不再要求重填 Key。Key 存在本地加固存储里：IndexedDB 中一把不可提取
（`extractable=false`）的 AES-GCM 密钥加密，密文放 localStorage。随手读
localStorage 的脚本或扩展只能看到密文。Key 只在本地加解密，从不发往服务端。
首页提供「清除已保存的密钥」。

## 缓存率从小数改为百分比

缓存使用率按百分比展示，末轮读取除以末轮总输入；字段缺失仍标 unknown，不伪造 0。

## 修复

- **`thinking.type.disabled` 被 claude-opus-5-5 拒绝**：IQ 自评那步固定发
  `disabled`，该模型返回 400，导致分数拿不回来。自评只要一个整数、不需要思考，
  改为不传 `thinking` 字段。实测 opus-5-5 / sonnet-5 / sonnet-4-5 / opus-4-6 /
  haiku-4-5 五个模型「不传」全部 200。
- **402 余额不足不再重试**：账户没钱时重发同样的请求只会得到同样的结果，此前会
  白烧 4 次重试，现在直接返回。404/405 不动——要留给协议回退。
- **5xx 文案**：明确写成「上游侧故障，非本站问题」，不再让用户误以为是检测站坏了。

## 界面动效

抽了一套动效令牌（缓动曲线、时长、位移、两级阴影），把按钮、输入框、图标按钮、
下拉选择器、状态码标签、结果卡片、历史条目统一到同一手感：悬停上浮 + 分层阴影，
按下缩放并压到 90ms，键盘聚焦有可见描边。系统开启「减弱动态效果」时自动关闭。
