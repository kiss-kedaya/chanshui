# v0.1.55

- 识图单独成板块：K 线读数从 IQ 卷里拆出来，题目 ID 改为 `vision`，每次检测随机生成 12 根 K 线图。IQ 卷回到 9 题共 100 分。
- 识图两个评分：图片被接受且读出一个整数记 50 分；数字答对再记 50 分，误差 ±2 记一半。卡片分开展示“识图成功/失败”和“答对/部分正确/答错”。
- 总分权重：指纹 30、推理 20、识图 15、注入 12、工具 8、联网 6、思维链 5、缓存 4。
- 指纹采样不再带思考等级：数字采样与行为探针都跳过站点默认的高思考等级，只发模型和 prompt。
- 公共接口与文档新增 `vision` 板块，支持单独跑；只跑识图时不产出 IQ 卷面。
- 指纹库同步到上游 `xqy2006/ModelTrace` 最新提交 `6cd4a8f`（18 个数字型号，加本地 DeepSeek 0910/1017 共 20 个）。
