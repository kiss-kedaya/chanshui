# 掺水？ v0.1.4

## 发布声明

本版本把知识截止从模型自报改成客观事件阶梯，并去掉历史卡片上的站点域名。报告页只放大分数和时间。

## 主要变更

- 知识截止用 13 道按季度排列的客观事件（2023Q4–2026Q3）。最新答对季度作为边界，展示为「知识≈2025Q4（7/13）」。不计入 IQ、接口完整性或指纹分。明确拒绝优先于正文里提到的答案；没有「最终答案」行时用回答末尾判分。
- 更早档位有两道以上明确答错时提示估计可能偏高。答对距检测日很近的事件时提示疑似联网。请求失败记为不确定，不算答错。
- 历史侧栏和报告标题不再显示站点域名。侧栏只保留放大的分数和时间。公开接口仍从服务端脱敏站点。
- 思维链回传拆成两项：思维摘要 5 分，signature 5 分。只有 Claude 前缀模型测这两项。
- 缓存读写仍是三轮串行短前缀，注入大小仍是独立探针，两者不合并。
