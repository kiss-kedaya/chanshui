# v0.1.30

修复后台指纹任务的流式兼容错误，减少无效重试，恢复失败项重试能力。

- Responses/Chat 指纹请求默认使用流式；Messages 保留非流式默认，上游明确要求流式时在同一路径切换。兼容性调整共用原有最多4次尝试预算。
- 鉴权、余额不足及无法适配的参数/路径错误不再重复发送；5xx 保留2/4/8秒加随机抖动的退避。
- 指纹遇到永久错误或整批请求耗尽重试后停止补采，避免持续故障时由10题放大成40次HTTP请求。成功但格式无效的响应仍允许在10题预算内补采。
- 数字样本不足3个时保留证据并标记探针失败，网页Job可重新提交密钥后重试失败项。证据增加实际协议、HTTP状态及尝试次数。
- Messages 流式解析收到 message_stop 或 [DONE] 后立即返回，避免等待连接关闭导致额外超时。

验证覆盖流式专用端点、协议保持、回退预算、永久错误、持续5xx、采样补偿、失败任务状态及流式结束事件。
