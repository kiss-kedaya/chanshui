# v0.1.54

- 模型名原样透传：删除 `api.deepseek.com` 上把 `deepseek-v4.1-flash` 改写成 `deepseek-flash` 的硬编码。用户填什么，请求体就发什么；报告里的“声称”与实际请求一致。
- 缓存链固定路由锚点：给第一条 user 消息永久加 `cache_control`，滑动断点仍跟随最新一轮。中转的粘性会话哈希取“第一条带断点的消息”，此前第三轮起哈希漂移会换号、整段缓存丢失。
- 去掉 `metadata.user_id` 注入：sub2api 只认 Claude Code 格式的 `device_id/session_id`，随手写的值会被忽略，还会让 UA 被判定成 Claude Code 客户端。撤销 v0.1.53 的做法。
- 缓存测试更新：第 1 轮 1 个断点，第 2 轮 2 个，第 3 轮起 3 个；跨轮校验首条 user 断点文案不变。
- 无缓存写字段的模型继续按读取链验证，末轮缓存率 = 末轮读取 ÷ 末轮总输入；缺字段不当 0。
