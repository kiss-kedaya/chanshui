# v0.1.8

缓存读写改为可选项，默认不测。勾选后按 6 轮串行多轮对话验证，并按网关实际出站字段读取缓存写入。

- 高级设置增加「缓存读写」，默认关闭。未勾选不发该探针，完整性分不占这 20 分。
- 勾选后固定同一前缀，回放上一轮 user 和 assistant，串行 6 轮。
- 通过条件：末轮读取与上一轮读加写相差不超过 64 token。
- 缓存率：末轮读取 / 末轮总输入。缺字段不当成 0。
- chat/responses 识别 `cache_write_tokens`、`cache_creation_tokens`、`cache_read_tokens` 等别名；嵌套字段优先。
- 注入大小仍单独检测。
