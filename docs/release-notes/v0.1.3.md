# 掺水？ v0.1.3

## 发布声明

本版本修复检测链路中的两个关键误判源，并完善公开报告安全边界。注入大小和缓存读写验证现在是两个独立探针；缓存没有观测到写入时只显示“无法验证”，不会把暖读命中误判为读写通过。

## 主要变更

- 注入大小使用两个带分隔符的独立短请求，避免连续字符被 BPE 合并；异常斜率、截断响应和思维文本污染不会计入注入评分。
- 缓存读写使用三轮递增对话：第一轮建立缓存，第二轮记录上一轮读取与新增写入，第三轮计算 `读取3 / (读取2 + 写入2)`；首、二轮没有正缓存写入时状态为 `unknown`。
- 工具调用 400/422 不再重复发送相同的 `tool_choice`；自动协议首轮降级保留工具选择，显式协议不跨协议切换。
- `/api/history`、`/api/detect/{id}`、`/api/reports/{id}` 默认只返回脱敏站点；只有对应 Job 操作 key 能解封当前任务 host。
- 删除“思考待定”“摘要已回传/未回传”等冗余状态文案，保留 Claude 专属思维文本与签名证据。
- 注入卡不再混入缓存读写列；缓存卡在无法验证时不显示伪造缓存率。
- 兼容 Job ID 分享、24 小时清理、操作 key 仅重试失败项和当前域名分享链接。
