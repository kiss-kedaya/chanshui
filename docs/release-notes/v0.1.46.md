# v0.1.46

开源准备与反馈管理 UI 收口。

## 反馈管理

- `/admin` 登录按钮不再因为口令长度不足而禁用；输入后可直接提交，由服务端判断。
- 增加管理员口令提示、初始会话检查、错误提示和自动聚焦。
- 反馈列表支持刷新、退出和导出当前 JSON；导出文件含联系方式，按敏感文件保管。
- 修复移动端右上角语言/主题工具遮住管理员“退出”按钮的问题。
- 管理员卡片与顶部工具之间保留间距，320/390 宽度无横向溢出。

## 开源准备

- Go module 改为 `github.com/kiss-kedaya/chanzhushui`，支持正常的 `go install` 路径。
- 重写 README，补充快速开始、Docker、运行参数、公共 API、安全边界和数据说明。
- 新增 `LICENSE`（MIT）、`SECURITY.md`、`CONTRIBUTING.md`、`THIRD_PARTY_NOTICES.md` 和 `.env.example`。
- 新增多阶段 `Dockerfile` 与 `docker-compose.yml`，默认只绑定回环地址。
- CI 增加 Docker 镜像构建和 `/api/health` 冒烟检查。
- `.gitignore` 增加反馈导出、日志、系统文件和 `.env.example` 例外。
- Release 工作流和本地打包脚本会带上许可证、安全说明、贡献指南和第三方声明。
- `cmd/fingerprint-capture` 不再内置特定网关默认地址，必须显式传 `-base-url`。
- 清理文档中的部署 IP 和特定证书路径；历史提交中的旧部署信息需在开源前单独处理。

## 验证

- Go 全量测试、`go vet` 通过。
- 前端 25 项测试、`typecheck`、`build` 通过。
- Playwright：登录按钮在空/短/完整口令下均可点击；正确口令登录、退出、错误口令提示均通过。
- 320/390 宽度管理员页面无横向溢出，顶部工具不再遮挡操作按钮。
- 无数据库迁移；使用双实例 + nginx 切流发布。
