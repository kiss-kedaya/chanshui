# v0.1.44

报告接口缓存与传输优化。

## 报告读取

- 已完成且没有可重试失败项的报告返回 `private, max-age=300, stale-while-revalidate=60`，同一浏览器刷新可直接复用。
- 运行中、排队中或存在失败项的报告继续返回 `no-store`，避免展示旧进度。
- 报告和历史响应补充 `Content-Length`；保留 ETag。
- 同时接受强 ETag 和雷池改写后的弱 ETag（`W/"..."`），条件请求可以正常返回 304。
- 前端报告和历史读取使用浏览器缓存；检测进度轮询仍为 `no-store`。

## 入口

- nginx 不再对 `/api/` 强制追加 `Cache-Control: no-store`，改由应用按报告状态设置。
- `/api/` 开启 `proxy_buffering`，减少 chunked 响应。
- nginx 显式对 JSON、JS、CSS、SVG 等类型开启 gzip，并允许代理请求压缩。

## 验证

- Go 全量测试、`go vet`、前端测试、`typecheck`、`build` 通过。
- 无数据库迁移；按滚动流程排空后切换。
