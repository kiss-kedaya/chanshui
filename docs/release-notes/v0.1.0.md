# 掺水？ v0.1.0

## 发布声明

这是“掺水？”检测站的首个可发布版本。它把网关黑盒检测收敛成一个本地可运行的 Go 服务和 Next.js 静态界面：提交检测后生成 Job ID，任务在服务端排队执行，报告保存 24 小时并可通过 ID 分享查看。

## 功能

- 注入大小使用两次独立短请求；缓存读写使用三次串行采样，两个项目分别显示实际用量并独立评分。
- ModelTrace 数字指纹与行为基线候选归因。
- 三请求缓存读写链和命中率信息。
- Claude 思维链摘要与签名回传检查；非 Claude 不展示该区块。
- 工具调用结构化参数、调用 ID 和结果回传校验。
- 有来源证据的联网搜索检测；不把模型自述当作联网证明。
- 模型自报知识截止日期，仅作 informational evidence，不参与评分。
- IQ 参数化测试，新增洗车、球拍与球、船锚水位；界面显示为 Q1～Q8，新报告使用新卷面，旧报告分值不变。
- 独立接口完整性分数：按覆盖率归一化协议、缓存、工具、联网、流式和思维链证据，不混入 IQ。
- Job 队列、24 小时清理、失败重跑、全站历史和分享链接。
- 暖橙/薄荷绿、日间/夜间主题，模型搜索下拉、加载动画、反馈入口。

## 运行

Release 包包含：

- `chanshui` Go 服务二进制
- `web/` Next.js 静态资源
- `README.md`
- `server-preparation.md`
- `VERSION`
- `checksums.txt`

运行参数、反向代理、数据目录、队列和安全边界见 `server-preparation.md`。Release 工作流只在推送 `v*` 标签后发布；本地构建不会上传或部署。

## 边界

知识截止、缓存、工具、联网、协议和注入属于证据区，不与 IQ 混分。单实例 SQLite 和内存队列适合便携部署；正式大流量上线前需要按服务器规格压测，并配置反代、限流、备份和可写数据卷。
