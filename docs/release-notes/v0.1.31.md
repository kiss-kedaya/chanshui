# v0.1.31

包含 v0.1.30 的后台任务修复，并修正发布测试中模拟内存驱逐的时序问题。v0.1.30 的发布构建未完成，生产升级使用本版本。

- Responses/Chat 指纹请求默认流式；Messages 默认非流式，上游要求流式时在原协议内调整后重试。
- 永久错误不重复发送，5xx 保留退避；整批指纹请求耗尽重试后停止补采，样本不足正确标记失败并保留证据。
- Messages 收到流式结束事件后立即返回，避免等待连接关闭。
- 模拟任务内存驱逐的测试等待数据库最终状态，避免在最后一次保存开始之前抢先删除内存任务。

详见 [v0.1.30 修复说明](v0.1.30.md)。
