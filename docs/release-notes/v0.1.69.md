- 缓存卡改为摘要（末轮缓存率、读取、输入、上一轮读+写），不再重复一张 14 行窄表；逐轮明细留在「推理表现」。
- 多轮对话卡在报告里占满整行，桌面和手机都不再挤在半宽列里。
