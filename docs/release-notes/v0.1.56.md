# v0.1.56

- 指纹归因改成三态：一致 / 可疑 / 假。跨家族，或 opus/sonnet/haiku 线对不上，判假，指纹 0 分；同家族但名称对不上（库内没有该名字）判可疑，给该板块 40% 分；低置信或样本不足按一致处理，不扣分。
- 总分权重下调指纹：指纹 30→18、推理 20→24、识图 15、注入 12→13、工具 8→10、联网 6→8、思维链 5→7、缓存 4→5，合计仍是 100。
- 旧报告不重算：详情页和侧栏列表都按当前三态重推，列表新增读取指纹系数，两边口径一致。
- 指纹卡：可疑用琥珀色印章和 warn 色文字，假仍是红色印章。
- 静态资源缓存：HTML 走 no-cache，`/_next/static/*` 走 immutable，发版后新 chunk 不会再被旧页面挡住。
