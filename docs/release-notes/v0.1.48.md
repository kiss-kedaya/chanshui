# v0.1.48

管理员后台重做视觉与交互。

## 布局

- 登录、反馈、指纹采集分成独立层级；登录后使用“反馈记录 / 指纹采集”标签切换，避免长页堆叠。
- 反馈列表和指纹表单统一为独立卡片，标题、说明和操作按钮分区。
- 指纹表单按“连接上游 / 归因信息 / 采样参数”分组；桌面两列、手机单列。
- 自定义指纹、采集进度独立展示，不再挤在表单底部。

## 控件

- 统一管理员按钮样式，区分主按钮、次级按钮和紧凑按钮。
- 协议选择改用站内自定义下拉，和前台检测页一致。
- API Key 增加显示/隐藏；模型名支持拉取列表后直接选择。
- 输入框、下拉框、卡片圆角和间距统一；桌面和 390/320 宽度无横向溢出。

## 验证

- Go 全量测试、前端测试、`typecheck`、`build` 通过。
- Playwright：标签切换、采集表单、协议下拉可见；桌面/手机无溢出。
- 无数据库迁移；双实例 + nginx 切流发布。
