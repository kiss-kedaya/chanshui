# 知识截止信息

知识截止不看模型自报的 YYYY-MM。模型会把训练边界说错，这个值不参与 IQ、接口完整性或指纹分。

探针是 13 道按时间排列的客观事件，覆盖 2023Q4 到 2026Q3。每题单独问，要求最后一行写「最终答案」。答对的最晚季度就是估计边界，展示为「知识≈2025Q4（8/13）」。更早档位有两道以上明确答错时，提示估计可能偏高。答对距检测日 45 天内的事件时，提示疑似联网。请求失败的题目算不确定，不算答错。

事件选择参考 yclenove/iqbench 的知识阶梯。LLMprobe-engine 的 submodel_cutoff 是直接追问 YYYY-MM，实测会被模型说错，所以没有沿用那一问。

旧报告里如果只存了 YYYY-MM，页面会标成「旧报告自报」，不会把它当成新的阶梯结果。
