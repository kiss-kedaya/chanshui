# 知识截止信息

检测任务新增独立的知识截止探针，询问模型自报的 `YYYY-MM`。

- 只展示信息，不参与 IQ、注入大小、模型归因、工具调用或联网检测分数。
- 只接受明确月份格式：`YYYY-MM`、`YYYY/MM`、`YYYY年MM月`。
- `UNKNOWN`、裸年份、无效月份和长篇自述显示为“未自报”。
- 结果标签明确写“模型自报”，不等同于训练数据事实，也不自动判定模型是否诚实。
- 参考 LLMprobe-engine 的 `knowledge_cutoff` / `submodel_cutoff` 思路；没有复制它的有害或不必要探针。

当前 IQ 仍只包含五道题。知识时效、缓存、工具、联网、协议和注入证据独立展示，避免把基础设施状态混入能力分数。
